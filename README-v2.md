# 视频分析工具 - 第二版本

## 🎯 项目概述

视频分析工具第二版本是一个强大的视频数字识别分析系统，支持多种OCR API提供商和智能降级策略。该工具专门用于分析视频中的数字变化，适用于条纹计数、测量数据分析等场景。

## 🆕 第二版本新特性

### 🔥 火山引擎OCR集成
- 集成火山引擎OCR API，提供高精度的数字识别
- 专门针对小数点识别进行优化
- 支持多种图像预处理策略

### 🤖 智能多API降级
- 自动检测可用的OCR服务
- 智能降级策略：火山引擎 → Tesseract.js → PaddleOCR
- 实时API状态监控和性能统计

### 🔧 全新配置管理
- 友好的可视化配置界面
- 支持API密钥安全管理
- 配置导入导出功能
- 实时提供商状态监控

### 📊 增强的分析功能
- 改进的小数点识别算法
- 多策略图像预处理
- 更准确的峰值检测
- 详细的分析统计信息

## 🚀 快速开始

### 1. 环境要求
- 现代浏览器（Chrome/Firefox/Safari/Edge）
- 网络连接（用于加载CDN资源）
- 火山引擎API密钥（推荐）

### 2. 使用方法

#### 方式一：使用原始版本（仅Tesseract.js）
打开 `index.html` 文件，使用原始版本的功能。

#### 方式二：使用第二版本（多API支持）
1. 打开 `index-v2.html` 文件
2. 点击"配置"按钮设置API密钥
3. 上传视频文件开始分析

### 3. 配置API密钥

#### 火山引擎API配置
1. 登录[火山引擎控制台](https://console.volcengine.com/)
2. 开通OCR服务并获取API密钥
3. 在工具中点击"配置"按钮
4. 填入API Key和API Secret
5. 选择合适的服务区域

#### Tesseract.js配置
- 无需额外配置，自动使用CDN资源
- 支持多种语言和识别模式

#### PaddleOCR配置（实验性）
- 需要部署PaddleOCR服务
- 配置模型下载路径

## 📋 功能详解

### 视频分析流程
1. **视频上传**：支持主流视频格式
2. **区域定义**：手动绘制亮度分析区域和OCR识别区域
3. **参数设置**：选择采样策略、滤波强度、峰值检测敏感度
4. **智能分析**：自动进行亮度分析和峰值检测
5. **OCR识别**：使用多种策略识别数字
6. **结果展示**：生成详细的分析报告和图表

### 多API支持
- **火山引擎OCR**：高精度商业API，推荐使用
- **Tesseract.js**：开源OCR引擎，无需配置
- **PaddleOCR**：百度开源OCR，实验性支持

### 配置管理
- **API提供商**：配置各种OCR服务
- **处理设置**：调整图像处理参数
- **状态监控**：实时查看API状态和性能
- **备份恢复**：导入导出配置文件

## 🔧 技术架构

### 前端技术栈
- **HTML5 Canvas**：视频处理和图像操作
- **JavaScript ES6+**：现代JavaScript特性
- **Chart.js**：数据可视化
- **Tesseract.js**：客户端OCR引擎

### 核心模块
- **config.js**：配置管理系统
- **volcano-ocr.js**：火山引擎OCR集成
- **ocr-manager.js**：统一OCR管理器
- **config-ui.js**：配置界面
- **enhanced-ocr.js**：增强OCR处理
- **signal-processor.js**：信号处理模块

### 设计模式
- **单例模式**：全局配置管理
- **工厂模式**：OCR提供商创建
- **策略模式**：多种图像处理策略
- **观察者模式**：状态变化通知

## 🐛 问题排查

### 常见问题

#### 1. OCR服务初始化失败
- 检查网络连接
- 验证API密钥是否正确
- 查看浏览器控制台错误信息

#### 2. 视频无法播放
- 确认视频格式支持
- 检查文件是否损坏
- 尝试不同的浏览器

#### 3. 识别结果不准确
- 调整OCR区域大小和位置
- 尝试不同的预处理策略
- 检查视频画质是否清晰

#### 4. 配置无法保存
- 检查浏览器是否支持localStorage
- 清除浏览器缓存后重试
- 确认没有隐私模式限制

### 调试技巧
1. 打开浏览器开发者工具
2. 查看控制台日志信息
3. 检查网络请求状态
4. 使用"测试OCR"功能验证设置

## 📈 性能优化

### 建议设置
- **采样策略**：根据视频长度选择合适的采样率
- **滤波强度**：中度滤波适合大多数场景
- **峰值检测**：中等敏感度平衡准确性和效率

### 最佳实践
1. 使用火山引擎API获得最佳识别效果
2. 精确定义OCR区域以提高识别准确率
3. 根据视频特点调整参数设置
4. 定期测试API连接状态

## 🔐 安全说明

### API密钥管理
- API密钥仅存储在本地浏览器
- 不会上传到任何服务器
- 建议定期更换API密钥
- 使用HTTPS连接保护传输安全

### 数据隐私
- 所有视频处理在本地完成
- 仅OCR识别部分会发送到API服务
- 可以选择纯本地的Tesseract.js引擎
